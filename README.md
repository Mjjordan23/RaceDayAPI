## Project Description

RaceDay API is a web API designed to manage sporting events. Organisers can create and manage events, while participants can register, enrol in events, and view race results.



## Technologies Used

- ASP.NET Core Web API
- SQL Server
- SQL Server Management Studio (SSMS)
- GitHub
- GitHub Actions

## Database

The `RaceDayDB.sql` script creates the RaceDay database, tables, relationships, constraints, and sample data.



## Setup Instructions

1. Clone the repository.
2. Open SQL Server Management Studio.
3. Open the `RaceDayDB.sql` file.
4. Execute the script to create the database.
